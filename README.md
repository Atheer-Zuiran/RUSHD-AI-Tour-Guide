# RUSHD - AI-Powered Smart Tour Guide Application

## Overview
RUSHD is a mobile application designed to enhance tourism experiences through AI-based landmark recognition. The app helps users identify landmarks and access relevant information instantly, with multilingual support to serve a diverse user base.

## Features
- AI-based landmark recognition using Gemini AI
- Multilingual translation support
- User-friendly mobile interface

## Technologies Used
- Flutter & Dart
- Android Studio
- Firebase
- Gemini AI
- Multilingual AI Translation

I led the development of this application, from initial concept through implementation, integrating AI capabilities with a functional mobile interface.
